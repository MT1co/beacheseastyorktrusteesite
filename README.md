# Jocelyne Poirier for TDSB Trustee — Ward 10

Campaign website for Jocelyne Poirier, candidate for Toronto District School Board (TDSB) Trustee in Ward 10 (Beaches-East York & Scarborough Southwest).

Built as a static site for GitHub Pages, based on the provided design mockup.

## Structure

- `index.html` — single-page site (hero, about, priorities, values, get involved, vote info, footer)
- `styles.css` — all styling
- `assets/images/jocelyne-headshot.jpg` — placeholder headshot cropped from the mockup; **replace with a final, high-resolution photo** before launch

## Local preview

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000

## Publishing with GitHub Pages

In the repo settings on GitHub: **Settings → Pages → Source → Deploy from branch → `main` / `/ (root)`**.
